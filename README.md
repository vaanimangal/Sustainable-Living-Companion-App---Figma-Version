# 🌱 About the Project

Sustainable Living Companion is a UI/UX case study designed to encourage environmentally responsible living through simple, engaging, and rewarding daily actions.

Inspired by the idea that **small habits grow into a greener future**, the application combines sustainability tracking, personalized goals, eco-friendly challenges, and progress visualization within an intuitive mobile experience.

---

# 🌿 Design Philosophy

> **"Every sustainable action is like planting a seed. Small efforts grow into lasting change." 🌳**

The interface embraces:

🍃 Natural color palette

🌿 Minimal and calming layouts

🌎 Easy navigation

🌱 Accessibility-focused design

🌳 Eco-inspired visual identity
